# Port Test Omissions

Tests in the Python reference SDK that this Ruby port deliberately
does NOT mirror. Each entry is a Python test name; the surrounding
section header gives the rationale.

## pytest fixtures misclassified as tests

The audit's regex picks up any `def test_…` definition. Python's
`tests/conftest.py` defines pytest fixtures named `test_data_dir` and
`test_utils` for use across the suite — they're not tests, they're
shared setup. Ruby uses Minitest helpers via inheritance / shared
modules instead.

- test_data_dir
- test_utils


`audit_test_parity.py` reads this file from the port root and
excludes the listed tests from its missing-test diff.

## LIMITATION (per SUBAGENT_PLAYBOOK.md)

`audit_test_parity.py` matches by normalized test name:
`test_add_body` / `test_addBody` / `it 'adds a body'` all collapse
to `testaddbody`. Ruby (Minitest) tests are mostly named in the
`def test_<snake_case>` form, but the test author's choice of
phrase often diverges from Python's. For example:

- Python: `test_add_body_and_bullets`  → `testaddbodyandbullets`
- Ruby:   `def test_section_with_body_and_bullets` → `testsectionwithbodyandbullets`

Both tests assert the same behavior; the audit can't see that
without reading the bodies. Where renaming a Ruby test would
clarify intent (and we already have an equivalent), we rename
the Ruby test to match Python. Where the test is genuinely
absent (e.g. CLI-tooling tests, mixin-internal tests that don't
apply to Ruby's single-class composition), it goes in the
relevant section below with rationale.

**The omissions below are NOT a list of bugs.** They cover four
categories:

1. Tests for subsystems Ruby doesn't ship (search, LiveWire shim,
   MCP gateway server, CLI tooling, Python-only example harness).
2. Tests for Python-style internal mixin classes that Ruby
   collapses onto AgentBase (single-inheritance + modules).
3. Tests with the same behavior but a different test name in Ruby.
4. Tests for narrow Python-specific behavior (asyncio, decorator
   syntax, type hint validation) that has no Ruby analog.
